# [기획봇] UX/UI 상세 설계서 — 북리뷰 열람 특화 & 읽기 전용 UI 개편

- **문서 버전**: v1.0
- **작성 에이전트**: 🎨 기획봇 (UX/UI Product Designer)
- **검수 에이전트**: 🤖 PM봇 (승인 완료: Read-Only 및 수동 동기화 원칙 100% 준수)

---

## 1. UX/UI 개편 핵심 방향성
기존 대시보드의 강점인 **시각적 통계(2026 히어로 카드, 4대 핵심 지표, 월별 추이, 책유형 TOP 6)**는 그대로 유지하면서, **Notion 원본 데이터를 오염시킬 수 있는 모든 편집(Write) 요소를 제거**하고 **'북리뷰와 에세이를 깊이 있게 읽고 공유하는 아티클 채널'**로 사용자 경험을 전환한다.

---

## 2. 영역별 상세 UI/UX 변경 명세

### 2.1. 헤더 (Header) — 수동 동기화 모드 명시 및 편집 버튼 정리
- **기존 UI (제거 대상)**:
  - `Notion DB 실시간 연동 중` (초록색 깜빡임 배지 및 API Key 입력 모달 트리거)
  - `[⚙️ 연동 설정]` 버튼 (프론트엔드에서 토큰을 입력받던 위험 요소 제거)
  - `[＋ 독서 후 글쓰기 등록]` 버튼 (Notion 쓰기 유발 버튼 완전 제거)
- **신규 UI (적용 사항)**:
  - **읽기 전용 상태 배지**:
    `🔒 수동 동기화 모드 (읽기 전용 · 마지막 동기화: YYYY-MM-DD HH:MM)` 형태로 현재 데이터 기준 시각과 안전한 읽기 전용 상태를 명확히 표시.
  - **우측 액션 영역**:
    1. **`[🔄 Notion 동기화]`**: 사용자가 직접 클릭했을 때만 `syncFromNotion(true)`를 호출하여 로컬 읽기 전용 브리지(`http://localhost:8000/api/sync`) 또는 최신 정적 JSON(`data/notion_books.json`)에서 변경분을 가져와 화면과 캐시를 갱신.
    2. **`[🎯 목표 수정]`**: 2026년 연간 목표 권수를 브라우저 `localStorage`에만 저장(Notion DB에는 영향 없음).

### 2.2. 대시보드 상단 & 중단 통계 영역 (유지 및 문구 고도화)
1. **2026년 목표 달성 히어로 카드**:
   - 상단 뱃지를 `📚 독서 후 글쓰기 북리뷰 채널 · 단방향 읽기 전용`으로 변경.
   - 원형 달성률 게이지, 선형 프로그레스 바, 목표 권수 변경(`localStorage` 전용) 유지.
2. **4대 핵심 요약 지표 (2x2 Grid)**:
   - `2026년 읽은 책`, `전체 누적 독서록`, `연도별 독서 성장 (2023→2026)`, `최다 선호 책유형` 그대로 유지.
   - 부가 정보로 외부 서평(브런치/블로그 등)이 연결된 도서 권수도 함께 안내.
3. **월별 독서 추이 & 책유형별 분포 TOP 6**:
   - 하단 인사이트 팁 문구를 `💡 도서 카드를 클릭하면 줄거리 요약과 독서 에세이 전문을 아티클 리더 뷰로 읽을 수 있습니다.`로 변경.

### 2.3. 필터 바 & 외부 서평 토글 필터 추가
- **연도별 필터 탭**: `전체 연도`, `2026년`, `2025년`, `2024년`, `2023년` 유지.
- **신규 토글 필터 추가**:
  - **`[✍️ 서평/링크 있는 책만 보기]`** 토글 버튼을 필터 바에 추가.
  - 클릭 시 `externalUrl`(브런치 `@crimson0425`, 네이버 블로그, 구글독스 등) 또는 본문 에세이가 등록된 도서만 즉시 필터링하여 북리뷰 채널 방문자가 읽을거리를 빠르게 탐색할 수 있도록 지원.
- **뷰 전환 및 검색/정렬**:
  - `🗂️ 카드 보기` / `📋 DB 표 보기` 전환, 검색창, 책유형 필터, 정렬(`완료일 최신순`, `완료일 오래된순`, `책이름 가나다순`) 유지.

### 2.4. 도서 카드 & DB 표 보기 — 순수 열람 및 서평 공유 특화
- **기존 UI (제거 대상)**:
  - 카드 및 테이블 내 `✏️(수정)`, `🗑️(삭제)`, `오늘 완독` 버튼 전면 제거.
  - 테이블 헤더의 `관리` 컬럼을 `독서록 / 서평` 열람 전용 컬럼으로 변경.
- **신규 UI (적용 사항)**:
  - 카드 전체 또는 `[📖 독서록 & 리뷰 읽기]` 버튼 클릭 시 아티클 리더 모달(`#essayModal`) 오픈.
  - **`externalUrl` 강조 배지**: 외부 서평 URL이 있는 책은 도서 카드와 테이블에 눈에 띄는 **`[🖋️ 브런치/외부 서평 읽기 ↗]`** (브런치 링크인 경우 `🖋️ 브런치 서평 읽기 ↗`, 블로그/기타 링크인 경우 `🖋️ 외부 서평 읽기 ↗`) 배지 버튼을 배치.

### 2.5. 북리뷰 리더(Reader) 모달 (`#essayModal`) 고도화
- **기존 UI (제거 대상)**:
  - 편집용 `<textarea id="essayBodyTextarea">`, `[✏️ 책이름/저자/... 수정]` 버튼, `[☁️ 본문 Notion에 실시간 저장]` 버튼 완전 제거.
- **신규 아티클 리더 뷰 (적용 사항)**:
  1. **헤더 메타데이터**: 책 아이콘(`emoji`), 책유형 배지, 연도, 완료일, 책이름(`title`), 저자(`author`)를 매거진 아티클 헤더 스타일로 배치.
  2. **줄거리 콜아웃 박스 (Summary Callout)**: `📌 핵심 줄거리 & 한줄평` 콜아웃 디자인 강화.
  3. **가독성 높은 독서록 본문 뷰어 (`#essayReaderContent`)**:
     - `textarea` 대신 정돈된 타이포그래피(`leading-relaxed`, 문단 간격, 인용구 스타일링)가 적용된 읽기 전용 아티클 컨테이너로 구성.
     - 본문 에세이(`bodyContent`)가 있으면 전문을 렌더링하고, 외부 서평(`externalUrl`)이 있으면 상/하단에 **`[🖋️ 브런치/외부 서평 전문 읽으러 가기 ↗]`** 프리미엄 배너 버튼을 제공.
  4. **하단 네비게이션 바**:
     - **`[← 이전 책]`** / **`[다음 책 →]`** 버튼을 배치하여 모달을 닫지 않고도 현재 필터링된 도서 목록의 북리뷰를 연속해서 넘겨 읽을 수 있도록 설계 (키보드 `←`, `→`, `ESC` 단축키 지원).
     - 우측에는 `[🔗 링크 복사]`, `[Notion 원본 보기 ↗]`, `[닫기]` 버튼 배치.
